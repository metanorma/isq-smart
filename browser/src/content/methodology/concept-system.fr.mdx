## Quatre niveaux sur trois axes

Le Navigateur ISQ organise chaque grandeur selon une hiérarchie à quatre niveaux sur trois axes parallèles :

### Niveau 0 : Type de grandeur
La catégorie la plus abstraite — un regroupement de grandeurs qui peuvent être comparées, additionnées et soustraites parce qu'elles partagent la même dimension.

### Niveau 1 : Grandeur
Un concept physique concret. « Longueur » (par opposition à « largeur » ou « hauteur ») mesure toutes le même type — elles peuvent être comparées et additionnées.

### Niveau 2 : Grandeur dédiée
Une grandeur liée à un type d'entité spécifique. « Longueur de tige » n'est pas la longueur abstraite ; c'est la longueur telle qu'appliquée aux tiges.

### Niveau 3 : Entrée
L'instance mesurée spécifique, par ex. « Longueur de la tige 3, mesurée 2024-03-15 ».

## Trois axes

- **Axe grandeur** — ce qui est mesuré (type → entrée)
- **Axe entité** — ce sur quoi porte la grandeur (type d'entité → individu nommé)
- **Axe mesure** — comment la mesure est exprimée (symbole → unités → valeur)
